# 好感度记账APP - 需求文档

## 核心概念

两个人建立情侣关系后，**各自给对方打分**。初始100分，做开心的事加分，惹生气扣分。最低0分，加分无上限。

## 功能模块

### 1. 用户
- 手机号注册/登录
- 编辑个人资料（昵称、头像、性别、简介）

### 2. 情侣关系
- 发起关系请求 → 对方确认 → 建立关系
- 双方各自初始100分
- 可解除关系

### 3. 好感度打分
- **不能给自己打分**
- 先创建"自定义加减分项目"，再用项目打分
- 加分项目：如"做了一顿好吃的饭 +10分"
- 扣分项目：如"忘了约会 -5分"
- 扣分时分数不低于0
- 可查看打分历史记录

### 4. 广场社区
- 发布动态（文字+图片）
- 点赞、评论（支持回复）
- 关注/取关用户

### 5. 聊天
- **互相关注后才能聊天**
- 实时WebSocket通信
- 消息历史

## 业务规则

| 规则 | 说明 |
|------|------|
| 初始分数 | 每人给对方100分 |
| 加分上限 | 无 |
| 扣分下限 | 0分 |
| 给自己打分 | ❌ 不允许 |
| 打分方式 | 必须选一个自定义打分项目 |
| 聊天条件 | 互相关注 |
| 关注 | 单向关注；双向为互关 |
